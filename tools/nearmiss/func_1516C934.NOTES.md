### THE FINDING: golden keeps a SECOND web for `arg1`, and the source had a second NAME for it

Golden makes a copy of `arg1` at the very top of the function and then reloads
`arg1->field_0x24` **through that copy** in the skip loop's preheader:

```

GOLD 227c  lw   t9,0x24(t0)      <- skip-loop preheader reloads field_0x24 THROUGH the copy
GOLD 2280  addu v0,t9,s3
```

Declaring a second source-level name for `arg1` and using it for the skip loop reproduces the
copy and the reload exactly:

```

MINE 227c  lw   v0,0x24(v1)      <- while (p->field_0x24[i] == 0xA) i++;
```

**Nothing else tried produces the copy at all** (≈120 variants this wave across nine batches).
This is the only construct that has ever moved the instruction count toward golden.

### Why `p` occupies the 8th local slot and `flags` does not

The frame decode (below) forces **exactly eight** 4-byte locals between `buf` and `w`. Seven are
forced by the codegen: `cond, i, len, first, dx, y, xoff`. The eighth was `flags` and is now `p`:

* `cond` is **required**: removing it and writing the overflow test as one bare `if` scores
  **2750 at 196 instructions** (loses 2 instructions). It is also the shape used by the two
  matched siblings, `func_1502C974` (game_58F80.c:329) and `func_151E8620` (game_215960.c:99).
* `flags` is **unobservable**: caching `*arg1->field_0x10` in a local and writing it inline at
  all three test sites are **byte-identical** (1723 both). IDO CSEs the three reads into golden's
  single `lw v0,0(t1)` either way. So the binary does not evidence `flags`, and it does evidence
  the arg1 copy — `p` gets the slot.
* Keeping BOTH (9 scalars) breaks the frame and scores 1997–2052.

`p` passes the load-bearing test: deleting it costs an instruction and 113 points (1836 @198).

### CAVEAT — this is a reading, not a proof

`p` is a semantically-inert *alias* of `arg1`, used at exactly one site (which is precisely what
golden's `move t0,s2` shows). It is honest in the sense that it is a real second name for a real
value and it moves the output toward golden — but if some *other* construct also produces a
second arg1 web, `flags` could be the true 8th local instead. Recorded as the current best
reading. **This function is NOT closed and must not be shipped as a match.**
